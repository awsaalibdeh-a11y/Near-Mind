# NearMind City

**The agent that makes neighbors neighborly, at city scale.** NearMind City has **5 neighborhoods, 20 buildings, 200 families
and 1,182 people**, with a NearMind robot on every roof. Each apartment is a family of 4 to 8 (parents, sons, daughters,
grandparents), and no name repeats anywhere in the city.

Anyone can ask for a small favor ("I need a ladder", "anyone up for a movie?"). Their building's robot works out who is likely
to have it and awake, asks only them, untangles vague replies, recommends the best offer and arranges the handover.
Every message is animated: you watch each bubble travel from an apartment up to the robot and back down.

**How you move around:** the city map → tap a neighborhood → tap a building → tap an apartment to ask as that family.

| Neighborhood | Buildings |
|---|---|
| 🌳 Al Noor Gardens | The Roof Robot Tower ★, Jasmine Court, Olive Grove House, Sidra Residence |
| 🌴 Palm Bay | Coral View, Pearl Tower, Dhow Harbour Flats, Sunset Terrace |
| 🏺 Old Souq Quarter | Saffron House, Lantern Building, Cardamom Court, Copper Gate |
| 🌙 Crescent Hills | Moonrise Heights, Juniper Block, Desert Rose Residence, Starlight Tower |
| 🦅 Falcon Heights | Skyline Lofts, Atlas Hall, Nova Apartments, Horizon House |

★ **The Roof Robot Tower** is the demo building: its ten families (**Sedra** 🎬, **Osama** 🧂, **Sulaiman** 🔧, **Asma** 🩹,
**Alwalid** 🍲, **Anas** 🎮, **Layla** 🧵, **Yousef** 🚴, **Noor** 🧁, **Hamza** ⚽ and their relatives) have illustrated portraits
and the five recorded demos. The other 19 buildings are generated by `city.py` from a fixed seed: every household gets a job,
a car or not, sleep hours, a private inventory (the kids' things too), a wish list and a budget. All of them work live.

## Run it

```bash
pip install -r requirements.txt
cp .env.example .env        # add OPENAI_API_KEY (model: NM_MODEL, here gpt-6.1-terra)
python app.py               # http://127.0.0.1:5215
```

- Pick who's asking (tap an apartment or a chip); the **family** card shows everyone who lives there.
- Type a request or tap a preset, and watch it play out. Time-of-day chips change the sky and who's asleep.
- **Why these neighbors?** shows who the robot picked and its reason for each, plus who it left in peace (and who was asleep).
- The **step tracker** (Understand · Ask · Clarify · Report · Hand over) lights up as the robot works; a **result** card sums up
  messages, people asked, people left in peace and AI rounds.
- **Fair:** the robot remembers who already helped in each building and spreads requests out; the decisions card shows
  **Helpers so far**.
- **Arabic or English:** write in Arabic and the robot asks neighbors and answers you in Arabic (try the **عربي** presets);
  bubbles and the timeline show Arabic right-to-left.
- **Never invents offers, enforced in code:** the server blocks the robot from reporting an offer before any neighbor has replied.
- **Hard to trick:** the code never lets the robot contact more than 3 neighbors per request, whatever anyone types; it refuses
  gossip, money loans and requests for card details, tells people to call 911 in a real emergency, and always answers the asker.
- **Sell** mode: a family lists something with a price; the robot finds who'd want it and the item goes to the buyer's door.
- **Watch a demo** (in The Roof Robot Tower) replays six recorded real runs instantly, one of them in Arabic. Re-record with `python tools/record_demo.py [name]`.
- When a deal closes, the item travels door to door and the camera zooms in on the receiver's door. `1×/2×` sets the pace.
- Rebuild the animation after editing `remotion/src/street.jsx`: `cd remotion && npm install && node build.mjs`.

## Put it online (from this computer)

**Permanent link: https://nearmind.awsaa-libdeh.workers.dev** (chat history: `/chat/jump`)

Double-click `start-public.bat` (after a restart too). It:
1. starts a second NearMind server in **public mode** on port 5218,
2. opens a free Cloudflare tunnel to it (`tunnel\cloudflared.exe`, a new `trycloudflare.com` address each time),
3. redeploys the small Cloudflare Worker in `worker/` so the permanent `workers.dev` link forwards to the new tunnel
   (`tools/update-link.ps1`; needs `npx wrangler login` once),
4. starts a **watchdog** (`tools/keep-public.ps1`) that checks the link every minute and restarts the server or opens a new
   tunnel by itself if either drops (free tunnels can expire). Its log is `tunnel\watchdog.log`.

- The link stays the same forever; the computer must be on, awake and online for it to work. If it's off, the link shows
  a friendly "NearMind is resting" page.
- The Worker stores no keys or visitor data. It passes the visitor's address to the server with a shared secret
  (`NM_PROXY_SECRET` in `.env`, also a Worker secret), so the per-visitor limits still work behind the proxy.
- The normal private server (`python app.py`, port 5215) is never exposed: it refuses tunnel traffic.

Public mode (`NM_PUBLIC=1`):
- Only the website, its API and the chat pages are served. WhatsApp, the old chat engine and any personal files are
  switched off (404).
- Every browser tab gets its own private street.
- Limits protect the API budget: `NM_HOURLY_PER_IP` (default 25 live requests an hour per visitor) and `NM_DAILY_CAP`
  (default 400 a day for the whole site). The recorded demos and chat pages never call the model.
- Shareable transcripts of the recorded runs: `/chat/jump`, `/chat/ladder`, `/chat/charger`, `/chat/sale`, `/chat/movie`.

## For WAICY judges

The WAICY 2026 rules for the LLM & AI Agent track, the submission text and the WAICY Day script are in [WAICY.md](WAICY.md).

- **ⓘ How it works** (or press `I`) explains the problem, the four steps, the AI inside and the responsible-AI rules.
- **⛶ Present** (or `P`) shows the building full screen for a live demo or screen recording; `Esc` exits.
- Shortcuts: `1`-`6` play the demos (movie night, ladder, charger at 00:30, selling a bike, jump-start at 6 AM, a ladder in Arabic), `S` speed, `R` reset.
- What the AI does: one router model replies in strict JSON (what it thinks, who to message, status changes); each neighbor is a
  separately simulated person that only owns what is in its private list, so the router has to ask to find out.
- Responsible by design: the router sees only public facts, never inventories; neighbors never see each other's chats; it asks as
  few people as it can; it skips people who are asleep unless it's urgent; it only relays what was actually said; the asker decides.

## WhatsApp (off for now)

The WhatsApp link is switched off; the page shows it on the side. When on, it runs the WhatsApp engine below.

`start-whatsapp.bat` runs `bridge/bridge.js`, which links to **your own WhatsApp** as a linked device (pairing code on
first run, shown in the app's WhatsApp panel).

- **Talk to NearMind** in your "Message yourself" chat. That chat is private: it shows only you and NearMind. Tick
  *Also show its chats with neighbors* in the panel to see everything.
- **Real neighbors**: in the panel, put a real person in a neighbor slot (name and number). They send your number any
  message once to join; after that NearMind asks them for favors and their real replies drive it.
- **Friends** you add can use NearMind from their own WhatsApp, with an AI street of their own.

Commands in the chat:

| Command | What it does |
|---|---|
| `/status` | who's on your street (real or AI, joined or not), the open request, what you owe |
| `/new` | fresh request; NearMind keeps what it learned |
| `/send` | deliver messages held for quiet hours now |
| `/reset` | forget everything (asks you to reply *yes*); opt-ins are kept |
| `/help` | the list |

**Real-neighbor etiquette, enforced in code:**
- NearMind never auto-replies in someone's private chat with you. It reads a neighbor's message only while it is waiting for
  their answer to its own question; anything else stays between you and them.
- Quiet hours (`NM_QUIET_START`/`NM_QUIET_END`, default 22-08): messages to real neighbors are held and sent at 08:00, unless
  the request is urgent. `/send` sends them now.
- No answer within `NM_REPLY_TIMEOUT_MIN` (default 15) minutes: NearMind tells you instead of waiting forever.
- The building view shows each real neighbor's live status: joined, awaiting reply, held, or not joined yet.

**Safety rules, enforced in code:** the bridge never starts a chat. It only messages you, or people who are on your list
**and** have messaged you first. Anyone can send `stop` to be removed. Groups are ignored.

### Meta Cloud API (optional)

To give NearMind its own number instead of yours, set `META_TOKEN`, `META_PHONE_ID` and `META_APP_SECRET` in `.env` and
point the Meta webhook at `/api/wa/cloud` (through the tunnel in `tunnel/`). A test number can only message recipients
verified in the Meta dashboard, and free text only within 24h of their last message.

## Files

| Path | What |
|---|---|
| `street.py` | the engine and its streaming API (`/api/street/*`, `/api/city`); works in any building |
| `city.py` | generates the city: neighborhoods, buildings, families of 4-8, unique names |
| `static/street.*`, `static/img/` | the website, portraits and backdrop |
| `remotion/src/street.jsx` | the animated building (built to `static/street-scene.js`) |
| `app.py` | Flask server: serves the site, plus the WhatsApp engine, commands and persistence |
| `bridge/` | WhatsApp linked-device bridge (Baileys) |
| `state.json` | NearMind's memory of your street (created at runtime) |
| `neighbors.json` | real neighbor slots (created at runtime) |

`state.json`, `neighbors.json`, `.env` and `bridge/auth`, `allow.json`, `jids.json` hold personal data and are git-ignored.
